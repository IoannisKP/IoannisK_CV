Agent X

Φοιτητικό project · Medieinstitutet Stockholm · 2026

Πώς θα μπορούσε η καθοδήγηση μέσα στο context του Escape from Tarkov, ενός hardcore survival shooter, να βοηθήσει νέους παίκτες χωρίς να μειώσει τη δυσκολία για την οποία το επιλέγει το κοινό του; Έκανα οκτώ συνεντεύξεις με παίκτες και συνέθεσα τα ευρήματα σε δύο personas και ένα journey map. Στη συνέχεια σχεδίασα τέσσερα wireframe views και τα δοκίμασα σε τρία think-aloud sessions.Έγινε με καθοδήγηση καθηγητών, στο πλαίσιο του προγράμματος UX. Ο πρώτος ολοκληρωμένος κύκλος έρευνας που έχω κάνει.

Τι προέκυψε Οι συμμετέχοντες βρήκαν και κατάλαβαν την καθοδήγηση χωρίς προτροπή.Το testing ανέδειξε επίσης περιορισμούς στη γλώσσα και στο δείγμα που χρειάζονται έναν ακόμη γύρο.

Το ερώτημα

Οι νέοι παίκτες εγκαταλείπουν νωρίς το Escape from Tarkov. Αν μειωνόταν η δυσκολία, θα χανόταν ο λόγος για τον οποίο το παίζει το υπάρχον κοινό του. Το brief ήταν να διερευνηθεί αν η καθοδήγηση μέσα στον κόσμο του παιχνιδιού θα μπορούσε να βοηθήσει έναν νέο παίκτη να προχωρήσει, χωρίς να αλλάξει αυτό που είναι το παιχνίδι.

Τι έκανα

  1. Οκτώ γραπτές συνεντεύξεις στο Discord, από αρχάριους έως έμπειρους παίκτες, ανάμεσά τους και ένας παίκτης που το είχε εγκαταλείψει.
  2. Σύνθεση σε δύο personas, τον Seeker και τον Returner, και σε ένα emotional journey map.
  3. Τέσσερα wireframe views ενός diegetic companion που ενεργοποιείται μόνο έπειτα από επανειλημμένη αποτυχία.
  4. Τρία think-aloud usability sessions πάνω στα wireframes.

Τι έδειξαν τα αποτελέσματα

Οι συμμετέχοντες εντόπισαν και κατάλαβαν την καθοδήγηση χωρίς να τους υποδειχθεί, που ήταν ακριβώς αυτό που εξεταζόταν. Τα wireframes δεν χρειάστηκαν επεξήγηση.

Τι θα έκανα διαφορετικά

Οι τρεις testers ήταν 40 έως 46 ετών και κανένας δεν είχε παίξει Tarkov, οπότε δεν ταίριαζαν στο προφίλ Seeker στο οποίο απευθύνεται το design. Έτσι, ένα screen που λειτουργεί μένοντας σκόπιμα σιωπηλό δεν μπορούσε να αξιολογηθεί σωστά. Ο επόμενος γύρος χρειάζεται πραγματικούς παίκτες από το target group, και η αναφορά το δηλώνει καθαρά αντί να το αποκρύπτει.

Radio

Προσωπικό project · καθοδήγηση ενός AI-assisted iOS build · 2026

Έφτιαξα ένα internet radio player για iOS μέσα σε μία εργάσιμη ημέρα, χωρίς να γράψω τον κώδικα. Όρισα το scope, χρησιμοποίησα έναν agent για το build και μετά έναν δεύτερο, ξεχωριστό agent για να ελέγξει το αποτέλεσμα. Στο τέλος το δοκίμασα σε φυσική συσκευή.Η δουλειά ήταν να ορίσω τις προδιαγραφές, να αμφισβητήσω το αποτέλεσμα και να το δοκιμάσω. Αυτό είναι product management, όχι engineering.

Τι προέκυψε Ο έλεγχος εντόπισε τέσσερα σφάλματα που έμοιαζαν όλα ολοκληρωμένα, και το device testing εντόπισε μια αστοχία δικτύου που είχε περάσει το code review.

Το ερώτημα

Αν ένας agent μπορεί να γράψει τον κώδικα, τι μένει για τον άνθρωπο που τον κατευθύνει; Ήθελα να το διαπιστώσω παραδίδοντας κάτι πραγματικό μέσα σε συγκεκριμένο χρονικό περιθώριο και παρατηρώντας πού είχε πράγματι σημασία η δική μου κρίση.

Πώς έγινε

  1. Το scope ορίστηκε και καταγράφηκε πρώτα, ώστε το «ολοκληρωμένο» να έχει ορισμό πριν κατασκευαστεί οτιδήποτε.
  2. Ένας agent έκανε το build βάσει αυτού του scope.
  3. Ένας δεύτερος, ξεχωριστός agent έλεγξε το αποτέλεσμα του πρώτου, με την παραδοχή ότι ήταν λάθος μέχρι να αποδειχθεί το αντίθετο.
  4. Testing σε φυσική συσκευή αντί για simulator.

Τι έδειξαν τα αποτελέσματα

Ο έλεγχος βρήκε τέσσερα σφάλματα σε δουλειά που παρουσιαζόταν ως ολοκληρωμένη. Στη συνέχεια, το device testing εντόπισε μια αστοχία δικτύου που είχε περάσει το code review, επειδή οι συνθήκες δικτύου του simulator δεν είναι ίδιες με ενός τηλεφώνου.

Τι κρατάω από αυτό

Το generation ήταν το φθηνό μέρος. Η αξία βρισκόταν στο να ορίσω με ακρίβεια τι έπρεπε να γίνει, να μην αποδεχτώ ένα αποτέλεσμα που απλώς έμοιαζε ολοκληρωμένο και να κάνω testing σε συνθήκες που μοιάζουν με πραγματική χρήση. Τίποτα από αυτά δεν απαιτούσε να γράψω κώδικα, και όλα απαιτούσαν να ξέρω τι να αντιμετωπίσω με δυσπιστία.
